# 课程评分

### 成绩构成（总分 100%）
| 项目 | 占比 |
|------|------|
| 期末考试 | 60% |
| 测验 1 | 10% |
| 测验 2 | 10% |
| 作业 1 | 5% |
| 作业 2 | 5% |
| 课堂参与 | 5% |
| **调查报告（Survey Report）** | **5%** |

### 作业与考试规定
- **作业**：不接受迟交。
- **测验与期末考试**：允许携带 **一张双面 A4 纸** 的参考材料（手写或打印均可），但**禁止粘贴便签/贴纸**。
- **缺考/缺勤**：若无有效病假证明（LOA/MC），则该部分成绩记 **零分**。
